# Labels are opaque text a land puts on each set it makes, for other tools
# to read back from `choros status`. A repeat is kept once, in the order
# first given. A repo that lands straight to main makes no set; its labels
# are kept on the land's line under `instant`.

$ choros work ws app
...
$ cd trunk/ws/app
$ choros repo bind app appq
app now lands into appq
$ echo a > a.txt && git add a.txt && git commit -qm "write a"
$ choros land continue --label tasks/xJ77 --label "b, c" --label tasks/xJ77
...
$ choros status
appq (app) @ $ROOT/trunk
* landing-1  front   write a (app)  #1  [tasks/xJ77, b, c]
* main
$ choros status --json | grep -A3 '"labels"'
          "labels": [
            "tasks/xJ77",
            "b, c"
          ],
$ cd trunk
$ choros work solo app
...
$ cd trunk/solo/app
$ echo s > s.txt && git add s.txt && git commit -qm "write s"
$ choros land continue --label tasks/xJ77 --session s-1
app → merged to main
$ choros status --json | grep -A20 '"instant"'
  "instant": [
    {
      "repo": "app",
      "workspace": "$ROOT/trunk/solo",
...
      "pr": null,
      "labels": [
        "tasks/xJ77"
      ],
      "sessions": [
        "s-1"
      ]
    }
  ]
}
$ choros land continue --label ""
choros: --label needs text
[exit 1]
